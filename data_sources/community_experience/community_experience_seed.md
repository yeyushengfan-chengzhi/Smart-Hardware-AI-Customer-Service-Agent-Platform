## 1. DDR4 / DDR5 平台取舍

### 条目 1.1
- **场景**：用户想在 DDR4 和 DDR5 之间选择平台，但误以为可以混用
- **经验要点**：DDR4 和 DDR5 物理插槽不兼容，防呆缺口位置不同，无法互插（强行插入会损坏插槽）。选主板时必须确定内存代别，不存在转接方案。
- **风险类型**：兼容性 / 物理损坏
- **适用条件**：首次装机 / 从 DDR4 平台升级
- **来源**：https://www.oscal.hk/blog/pcs/desktop/can-ddr4-ram-work-with-ddr5-slot
- **可信度**：medium（已被多方社区验证）

### 条目 1.2
- **场景**：用户预算有限，纠结是否为了"未来升级"多花钱上 DDR5
- **经验要点**：12 代/13 代 Intel 部分主板同时提供 DDR4 和 DDR5 版本（如 B760 DDR4 vs B760 DDR5），但 AM5 平台仅支持 DDR5。如果选择 DDR4 版 B760，内存无法带到下一代平台，升级路径受限。
- **风险类型**：升级路径锁定
- **适用条件**：预算装机 / 12 代 Intel 平台 / 未来计划升级
- **来源**：https://www.techbloat.com/can-you-run-ddr4-ram-on-a-ddr5-motherboard-a-compatibility-analysis.html
- **可信度**：medium

### 条目 1.3
- **场景**：用户听说 DDR5 更快，想买高频条但主板/CPU 实际不支持
- **经验要点**：DDR5 标称频率（如 6400 MT/s）需要主板和 CPU 内存控制器都支持，部分入门主板和早期 CPU 在高频下不稳，可能需要手动降频使用。购买前应确认主板 QVL 列表。
- **风险类型**：性能降级 / 不稳定
- **适用条件**：选购高频 DDR5 / 入门级主板
- **来源**：https://overclockers.ru/blog/cool-gadgets/show/183831/DDR5-4800-vs-DDR5-6400
- **可信度**：medium

## 2. AM4 / B550 / Ryzen 5600 预算平台经验

### 条目 2.1
- **场景**：用户购买 Ryzen 5 5600 + B550 主板组合
- **经验要点**：Ryzen 5 5600 搭配 B550 主板，大多数 2020 年中以后出厂的 B550 主板已原生支持 Ryzen 5000 系列，无需刷 BIOS。但若买到库存旧版，可能需要 BIOS 更新才能点亮，建议认准"Ryzen 5000 Ready"标识。
- **风险类型**：BIOS 兼容性 / 无法点亮
- **适用条件**：Ryzen 5600 + B550 组合 / 购买旧库存主板
- **来源**：https://www.aliexpress.com/p/wiki/article.html?keywords=ryzen-5-5600-compatibility-b550
- **可信度**：medium

### 条目 2.2
- **场景**：用户对比 B450 和 B550 主板，为省钱选择 B450
- **经验要点**：B450 仅支持 PCIe 3.0，B550 支持 PCIe 4.0。如果搭配 PCIe 4.0 NVMe SSD，B450 会降速到 PCIe 3.0，实际日常使用差异不大但跑分有差距。B550 通常还附带 2.5G 网卡和更好的 VRM 散热。
- **风险类型**：性能取舍 / 功能缺失
- **适用条件**：预算有限 / B450 vs B550 抉择 / 使用 PCIe 4.0 SSD
- **来源**：https://www.facebook.com/groups/372119787729533/posts/1276824047259098/
- **可信度**：medium

### 条目 2.3
- **场景**：用户在 AM4 平台上搭配高端显卡或考虑未来升级
- **经验要点**：AM4 是末代平台（已被 AM5 取代），Ryzen 5000 系列是 AM4 最终代 CPU。选择 AM4 意味着未来升级 CPU 的上限是 Ryzen 9 5950X / 5800X3D，无法升级到 Ryzen 7000/9000 系列。如果计划未来 2-3 年内升级 CPU，建议多考虑 AM5。
- **风险类型**：平台锁定 / 升级路径
- **适用条件**：AM4 新装机 / 计划未来升级 CPU
- **来源**：https://www.reddit.com/r/buildapc/comments/10ui60m/budget_am4_motherboard_with_pci_40_for_5600_and/
- **可信度**：medium

## 3. Intel B760 DDR4 / 12400F 预算平台经验

### 条目 3.1
- **场景**：用户选择 i5-12400F + B760 DDR4 主板
- **经验要点**：B760 芯片组原生支持 Intel 12/13/14 代 CPU。i5-12400F 搭配 B760 DDR4 主板是成熟的预算方案，但 B760 主板有 DDR4 和 DDR5 两个版本，购买时必须确认是 DDR4 版，买错则内存插不进去。
- **风险类型**：购买错误版本
- **适用条件**：选购 B760 主板 / 已有 DDR4 内存
- **来源**：https://www.youtube.com/watch?v=2JNxKTcsKEw
- **可信度**：medium

### 条目 3.2
- **场景**：用户为省钱选择 H610 而非 B760 搭配 12400F
- **经验要点**：H610 芯片组相比 B760 缺少 PCIe 4.0 支持（仅 PCIe 3.0）、M.2 插槽更少、内存超频受限（不支持 XMP 高频率）、USB 接口更少。如果预算允许，多花一点上 B760 获得更好的扩展性。
- **风险类型**：功能缺失 / 扩展受限
- **适用条件**：H610 vs B760 抉择 / 需要 M.2 扩展
- **来源**：https://dzen.ru/a/Z-VeGKDXDnkXTXke
- **可信度**：medium

### 条目 3.3
- **场景**：用户购买廉价 B760 DDR4 主板后发现 VRM 散热不足
- **经验要点**：部分入门级 B760 DDR4 主板 VRM 供电相数较少且散热片简陋，搭配 12400F 没问题，但如果未来升级到 i7-13700/i7-14700，VRM 温度可能过高导致降频。购买前建议查看主板 VRM 实测。
- **风险类型**：升级限制 / 供电不足降频
- **适用条件**：入门级 B760 / 计划升级 i7
- **来源**：https://rutube.ru/video/8b93bdcab4404f692f22868f2ec09659/
- **可信度**：medium

## 4. M-ATX 主板装 ATX 机箱观感

### 条目 4.1
- **场景**：用户选择 M-ATX 主板装入 ATX 中塔机箱
- **经验要点**：M-ATX 主板尺寸（244×244mm）装入 ATX 机箱在物理安装上完全兼容，但主板下方会留下约 6-8cm 的空旷区域。追求"饱满"视觉效果的用户可能会觉得不够美观，尤其在海景房/侧透机箱中更明显。
- **风险类型**：外观观感（非功能性）
- **适用条件**：M-ATX 主板 + ATX 机箱 / 侧透/海景房机箱
- **来源**：https://www.sohu.com/a/830330002_122006510
- **可信度**：low（主观审美）

### 条目 4.2
- **场景**：用户先买 ATX 机箱打算以后换 ATX 主板
- **经验要点**：先买 ATX 机箱配 M-ATX 主板，以后再换 ATX 主板，这在装机顺序上是可行的。但 M-ATX 主板放到 ATX 机箱中走线反而更轻松，因为底部空间充足；真正需要担心的是反过来——M-ATX 机箱无法装 ATX 主板。
- **风险类型**：走线 / 逆向不兼容
- **适用条件**：分期升级 / M-ATX 机箱装 ATX 主板
- **来源**：https://tieba.baidu.com/p/9027324066
- **可信度**：medium

## 5. 厚显卡与底部风扇空间风险

### 条目 5.1
- **场景**：M-ATX/ITX 机箱底部加装风扇后与厚显卡冲突
- **经验要点**：部分 M-ATX 机箱主板显卡插槽做了下沉设计（非第一槽），导致显卡更靠近底部。如果使用 3 槽厚度显卡（如 RTX 4080/4090 非公版），底部基本无法安装标准 25mm 厚度风扇，只能使用 15mm 薄扇或放弃底部风扇。
- **风险类型**：物理干涉 / 散热受限
- **适用条件**：M-ATX 小机箱 / 3 槽厚显卡 / 底部加装风扇
- **来源**：https://www.bilibili.com/video/BV1DdAoekEgg/
- **可信度**：medium

### 条目 5.2
- **场景**：用户购买显卡只关心长度，忽略厚度
- **经验要点**：许多新手只关注"显卡长度 < 机箱支持长度"就认为可以安装，但忽略了厚度（槽数）。3 槽以上厚卡在小机箱中可能贴底或顶侧板，导致散热空间不足、显卡风扇紧贴底部进风不畅。购买前需同时确认长度、厚度、高度三个维度。
- **风险类型**：物理干涉 / 散热差
- **适用条件**：小机箱 / 3 槽以上厚显卡
- **来源**：https://bottleneckcalculator.to/en/gpu-clearance/
- **可信度**：medium

## 6. 前置 360 冷排影响显卡长度

### 条目 6.1
- **场景**：用户在机箱前面板安装 360mm 水冷排后，发现显卡装不下
- **经验要点**：机箱标注"支持 360mm 冷排"和"支持 400mm 显卡"通常是两选一的关系。前置安装冷排（含风扇，总厚度约 55mm）后，实际可用显卡长度 = 机箱标称显卡长度 - 55mm。例如机箱标称 360mm 显卡支持，装前置 360 冷排后仅剩约 305mm。
- **风险类型**：空间冲突 / 无法安装
- **适用条件**：前置安装 360 冷排 + 长显卡
- **来源**：https://evezone.evetech.co.za/build-lab/360mm-radiator-compatibility/
- **可信度**：medium

### 条目 6.2
- **场景**：用户已购买长显卡（三风扇 RTX 40 系列），计划加装前置 360 水冷
- **经验要点**：RTX 4080/4090 部分非公版长度超过 340mm，在多数 ATX 中塔机箱中前置 360 冷排后空间不够。解决方案：① 选择顶部安装 360 冷排（需确认顶部空间）；② 选择 240/280 冷排前置；③ 选择更大的全塔机箱。
- **风险类型**：空间冲突 / 需更换配件
- **适用条件**：340mm+ 显卡 + 前置 360 水冷
- **来源**：https://www.bilibili.com/video/BV1BXwczXELR/
- **可信度**：medium

### 条目 6.3
- **场景**：用户在紧凑型 ATX 机箱中同时追求大冷排和长显卡
- **经验要点**：部分机箱（如分形工艺 North）在保留硬盘架的情况下不支持前置 360 冷排；即使拆掉硬盘架，前置 360 冷排与长显卡的共存也需要精确测量。建议装机前用机箱厂商官网的兼容性检查工具核验。
- **风险类型**：多配件冲突 / 安装复杂
- **适用条件**：紧凑 ATX / 多 HDD 需求 + 360 冷排 + 长显卡
- **来源**：https://zhongce.sina.com.cn/iframe/article/view/161723/
- **可信度**：medium

## 7. 顶部水冷可能顶内存或主板 VRM 散热片

### 条目 7.1
- **场景**：用户在紧凑型机箱顶部安装 360 水冷排后，冷排/风扇与主板 VRM 散热片冲突
- **经验要点**：部分主板 VRM 散热片较高（如 ROG 高端系列），在顶部安装 360 冷排时，风扇边缘会与 VRM 散热片或 CPU 8-pin 供电线干涉。尤其是 Meshify C 等紧凑 ATX 机箱中此问题常见。
- **风险类型**：物理干涉
- **适用条件**：紧凑型 ATX 机箱 + 高 VRM 散热片主板 + 顶部 360 冷排
- **来源**：https://forums.pcgamer.com/threads/gpu-clearance-issues-meshify-c.143716/
- **可信度**：medium

### 条目 7.2
- **场景**：用户在 MATX/ITX 小机箱顶部装水冷排后发现与内存冲突
- **经验要点**：在小机箱（特别是 ITX）中，顶部安装 240/280 冷排时，风扇可能超出主板边缘顶到高马甲内存。建议超 40mm 高的内存条在 ITX 机箱中慎重选择顶部水冷方案。
- **风险类型**：内存兼容性 / 物理干涉
- **适用条件**：ITX/MATX 机箱 + 高内存 + 顶部水冷
- **来源**：https://linustechtips.com/topic/1137619-motherboard-vrm-tier-list-v2-currently-amd-only/page/47/
- **可信度**：medium

### 条目 7.3
- **场景**：用户装机后发现顶部冷排风扇与内存实际间隙不足
- **经验要点**：即使物理上没有硬干涉，顶部冷排风扇紧贴内存（间距 < 2mm）也可能导致风扇运行时产生口哨声或振动噪音。建议安装前预留至少 3mm 间隙。
- **风险类型**：噪音 / 振动
- **适用条件**：顶部水冷 + 高马甲内存 + 紧配合
- **来源**：https://www.youtube.com/watch?v=BbGomv195sk
- **可信度**：low（社区经验，缺乏系统测试）

## 8. 双塔风冷挡高马甲内存

### 条目 8.1
- **场景**：用户购买双塔风冷后，发现前风扇挡住内存插槽
- **经验要点**：双塔风冷（如 NH-D15、Peerless Assassin 120、Dark Rock Pro 4）的前风扇通常覆盖内存区域。标准 32mm 内存通常没问题，但超过 45mm 的高马甲/灯条会被风扇挡住。解决方案：① 抬高风扇位置（需机箱宽度支持）；② 将风扇移到散热器后方改为吸风；③ 拆掉前风扇单靠中置风扇。
- **风险类型**：物理干涉 / 散热性能折损
- **适用条件**：双塔风冷 + 灯条/高马甲内存
- **来源**：https://www.zhihu.com/question/587574680
- **可信度**：medium

### 条目 8.2
- **场景**：用户购买"内存无遮挡"设计双塔散热器但仍有兼容问题
- **经验要点**：部分新型双塔散热器（如九鲨 JF15K）采用偏置热管或抬高鳍片设计，标称支持 53mm 高内存。但实际装机中，内存进入散热器下方后可能影响气流，且 RGB 灯条被散热器完全遮挡失去视觉效果。使用无光内存是更实际的选择。
- **风险类型**：视觉遮挡 / 气流影响
- **适用条件**：偏置双塔散热器 + 高 RGB 内存
- **来源**：https://zhongce.sina.com.cn/iframe/article/view/191161/
- **可信度**：medium

### 条目 8.3
- **场景**：用户不确定自己的内存能否搭配某款双塔散热器
- **经验要点**：购买前应同时核对三组数字：① 内存高度（mm，含马甲）；② 散热器标称内存兼容高度（通常 32-45mm，偏置型可达 53mm）；③ 机箱 CPU 散热器限高（含风扇抬高后的总高度）。三者任一不满足都可能导致装不上或盖不上侧板。
- **风险类型**：多重兼容性 / 侧板盖不上
- **适用条件**：选购双塔风冷 + 未知内存高度
- **来源**：https://www.pcworld.com/article/3052246/dont-let-ram-clearance-wreck-your-pc-build.html
- **可信度**：medium

## 9. 小机箱装机走线难度

### 条目 9.1
- **场景**：首次装机选择 ITX 或紧凑 MATX 机箱
- **经验要点**：ITX 机箱内部空间极紧凑，配件安装有严格顺序（通常须先装主板再装电源最后走线），一旦顺序错误就可能需要全部拆掉重装。原厂电源线材又长又硬，在 ITX 机箱中整理极为困难，建议新手从 MATX 起步。
- **风险类型**：安装难度 / 时间成本
- **适用条件**：首次装机 / ITX 机箱 / 非模组电源
- **来源**：https://post.smzdm.com/p/aomegwg9/
- **可信度**：medium

### 条目 9.2
- **场景**：用户在小机箱中使用标准 ATX 电源
- **经验要点**：小机箱搭配标准 ATX 电源（非 SFX）时，电源线材过长需要大量整理，背线空间通常不足，硬塞可能导致背板鼓包。建议使用定制短线或模组电源 + 定制模组线，或直接选择 SFX 电源。
- **风险类型**：背板无法闭合 / 线材挤压
- **适用条件**：ITX/MATX 机箱 + ATX 电源
- **来源**：https://www.reddit.com/r/sffpc/comments/1deybo5/best_itx_case_for_cable_management/
- **可信度**：medium

## 10. 海景房机箱风道注意事项

### 条目 10.1
- **场景**：用户装机后海景房机箱内部温度高（"闷罐"）
- **经验要点**：海景房机箱因正面和侧面为玻璃面板，无法像传统机箱那样正面进风。最佳风道方案通常是：底部进风（反叶风扇）→ 顶部出风 + 后部出风 + 侧面进风。如果所有风扇都设为出风（负压），会导致进风不足和积灰加速。
- **风险类型**：散热不良 / 积灰
- **适用条件**：海景房机箱 / 双面玻璃 / 风扇配置错误
- **来源**：https://www.zhihu.com/question/582123807
- **可信度**：medium

### 条目 10.2
- **场景**：用户海景房机箱侧面风扇装反方向
- **经验要点**：海景房机箱侧面通常用于进风（将外部冷空气送入机箱），如果侧面风扇设成出风，会把底部进来的冷空气直接从侧面排出，形成短循环，CPU 和显卡区域的散热效果大打折扣。建议侧面进风、底部进风、顶部和后部出风。
- **风险类型**：风道短路 / 散热效率低
- **适用条件**：海景房机箱 / 侧面风扇方向错误
- **来源**：https://www.chiphell.com/thread-2553152-1-1.html
- **可信度**：medium
